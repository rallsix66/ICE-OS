## 1. 包边界

- 交付：`/dashboard` 首页（三阶段、市场分布、商品库存概览、真实待处理、数据时间、未计入说明）、
  一级导航首页入口、登录默认进入首页、首页所需服务端汇总与估值。
- 不交付：低库存风险/未来七天到货等缺少业务依据的指标；首页操作日志区；跨阶段总资产；
  新的成本/权限/预测模块。
- 不修改：库存同步 worker、物流读取进程、既有读取契约与数据库结构；不新增表、不改既有 RPC。
  首页只调用现有只读入口；不触发同步、不写业务数据。

## 2. 首页结构

1. 页头：标题「经营总览」；右侧「查看商品库存」入口。
2. 数据时间条：国内文件日期、海外最近成功、在途最近成功，分别标注，不写成同一时点。
3. 三阶段卡片（国内库存 / 物流在途 / 海外库存）：实物数量、已知估算货值、已计价/未计入、
   数据时间与明细入口；海外额外保留「已知小计、合计待核对」标记。三阶段不合并成总资产。
4. 海外市场分布：市场、海外实物、库存已知货值、在途剩余、在途已知货值、库存/在途两个下钻入口；
   「市场待确认」单独一行。
5. 需要处理：库存待对应、物流待复核、在途未计入、缺进货价、来源失败/未运行等真实事项，
   每项显示真实数量与处理入口；没有待办时显示明确空态。
6. 未计入说明（默认收起）：缺进货价、海外合计待核对、未对应、数量待核、市场待确认的件数与
   商品清单，可展开查看并进入处理页。
7. 商品库存概览：国内 ∪ 海外 ∪ 已绑定在途商品；展示商品/货号、国内实物、海外实物、
   已知剩余在途（金额权限内加已知货值）、「详情」「货票」入口；支持搜索与分页。
8. 来源与口径页脚：三阶段来源、估算货值口径、金额权限/成本失败提示。

## 3. 指标口径与来源（全部复用现有读取）

| 指标 | 口径 | 来源 |
|---|---|---|
| 国内实物合计 | 冻结聚水潭表格快照中「已核对选择且关联标准商品」的「实际库存数」合计；缺失/非法/冲突不计入并计数 | `getInventoryDomesticSnapshot`（冻结文件，SHA 校验） |
| 国内估算货值 | 国内已计入实物数量 × 商品库当前采用进货价（人民币、单品、不含运费） | 同上 + `catalogRepository.baselineAmountsMap` |
| 海外实物合计 | 各参与仓当前有效批次 adopted 行按标准商品合计的 on_hand；多单位/未知不凑数 | `getInventoryProductSummary`（按完整范围分页取全，limit≤200/页，直到 `total`） |
| 海外已知小计与待核对 | 商品汇总 `knownSubtotal` 数量；`hasPendingTotal` / `knownSubtotalComplete=false` 时标记「合计待核对」，不重新合并双码 | 同上 |
| 海外估算货值 | 已知小计 × 采用进货价；缺价数量单列；待核对商品金额标「已知小计」 | 同上 |
| 在途剩余数量 | 飞书当前成功读取的「剩余在途」；数量待核不计；已全部上架计 0；未关联商品单列 | `read_shipment_market_summary('all')` → `buildShipmentMarketSummary` |
| 在途估算货值 | 已知剩余 × 采用进货价；缺单价保留数量不计金额；冲突待复核不计 | 同上 + 批量采用进货价 |
| 市场分布 | 海外库存按仓库市场证据分组；在途按来源「国家」分组；市场待确认单列 | 商品汇总市场格 + 在途市场汇总 |
| 商品覆盖 | 国内 ∪ 海外 ∪ 已绑定在途商品（按标准商品去重） | 商品汇总 + 国内快照 + 在途商品汇总 |
| 库存待对应 | 当前商品库存范围未对应来源行（来源 SKU × 仓库） | `inventory_sync_overview.mappingQueueTotal` / 022 `unmappedOverseasRows`；与同步页 219（含排除仓 78）的差异在页面文案说明 |
| 物流待复核 | 拆/合票待确认事项数 | `read_shipment_grouping_reviews` → `pending.length` |
| 在途未计入 | 未关联/数量待核/缺单价/待复核条数 | 在途汇总 `excludedByReason` |
| 来源失败/未运行 | 库存 worker 在线/启用/账号状态/最近任务；飞书最近尝试失败与自动读取状态 | `inventory_sync_overview` + `read_shipment_source_status` + `read_shipment_auto_reader_status` |
| 数据时间 | 国内=冻结文件日期；海外=最近成功批次观测时间/范围最后全部成功；在途=最近成功读取 | 同上各读取 |

金额只取 `amount:read` 权限；无权限时隐藏金额并说明。成本读取失败时单独显示「进货价读取失败」，
保留数量，不计算金额、不判断缺价、不生成补价待办，也不显示成「无金额权限」或 0 缺价。

## 5. 未知与零、失败与旧数据

- 数量未知、单位冲突、数量待核：显示「待核/未计入」并计入未计入说明，不写 0，不并入合计。
- 真实 0：来源明确为 0 时显示 0；与「未读取/未知」分开表达。
- 已知小计但合计不完整：保留已知数量与金额，标「合计待核对 / 已知小计」，不当作完整合计。
- 来源失败：保留最近成功数据与时间并显示失败状态；不把失败写成空或 0；国内与在途各自降级。
- 三阶段来源时点不同：不提供合计总资产，页面明确说明。
